# パーツ細分化

`PostProcess → Refine Details (Candidates) → Save PSD` と接続します。
既存のアップスケールを使用する場合は、細分化を最後のアップスケール後に
置くと、切り出した境界の補間によるずれを避けられます。

## 自動候補

- 鼻: モデルが出した `nose` を保持します。未検出ならレポートに表示します。
- 目のハイライト: `eyes` / `eyel` / `eyer` / `irides` / `iridesl` / `iridesr` / `irides-l` / `irides-r` 内の局所的に明るい領域。
- 髪のハイライト: 前髪・後ろ髪の明るい領域。
- 髪束: 輪郭の距離ピークと画像の境界を使った watershed の分割候補。
- アクセサリー: 頭飾り・耳飾り・首飾り・眼鏡・objects の離れた領域を個別化。

`minimum_area` は小さなノイズを除外する画素数です。微小な反射光を残す場合は下げます。
`highlight_contrast` を下げると暗いハイライトを拾いやすくなりますが、誤検出も増えます。
`max_hair_locks` は髪束候補の上限です。指定した数への強制分割ではありません。
`part_names_and_report` は後続ノードに指定するパーツ名と検出結果を返します。

## 手動補正と色調整

`Extract Detail by Mask` に同じキャンバス寸法の単一MASKを接続し、
`source_part` に `face` や `front hair`、`new_part_name` に `nose_detail`、
`hair_lock_01`、`hair_accessory_01` などを指定します。
白い領域（しきい値より大きい領域）が切り出されます。
ComfyUIのLoad ImageのMASK出力はアルファの反転なので、実際のマスクを確認してください。
名前は英数字・アンダースコア・ハイフンのみ、重複名はエラーになります。
必要な数だけノードを連結できます。

`Edit Detail Color` に切り出したパーツ名を指定すると、明るさ・彩度を個別調整できます。
最終的な各パーツは標準のPSD出力へそのまま渡せます。

## 限界

これは既存モデル出力の後処理です。新しい意味カテゴリを学習したモデルではありません。
鼻の未検出や、髪に融合したアクセサリーを自動で新規認識することはできません。
白髪、白目、強い照明、線がつながった髪束では、候補を確認してマスク補正してください。
髪束を1本ずつ正しく識別する保証はありません。

元のRGBA画素を重複なく配分し、分割前の見た目を保存します。髪束間の境界や小片は
元パーツに残すため、元パーツもPSDで残してください。隠れた部分の描き足しは行いません。
切り出したパーツを移動・非表示にすると、その下に穴が開く場合があります。
Live2Dで大きく動かす場合は、下地の補完を別途行ってください。

## 検証

`python -m unittest discover -s tests -v`

必要依存: NumPy、OpenCV。ノード実行には通常のComfyUI/PyTorch環境が必要です。
