# 横向きの反応と会話時の開口を強める

Issue #25の設定です。`Revenant_Natural` の頭Xと口開閉の追跡だけを調整します。[直前の髪の調整](live2d-hair-motion.md)、首の上下・横傾き・体・目・笑顔判定は保持します。個人モデル・画像・認証設定は公開Gitに含めません。

その後の[動きと輪郭の調整](live2d-motion-balance.md)では、口の設定を保持したまま頭X出力を±36へ強めています。

| VTSマッピング | 変更前 | 変更後 |
| --- | --- | --- |
| 頭Xの入力 | −30〜30 | 同じ |
| 頭Xの出力 | −21〜21 | −27〜27 |
| 口開閉の入力 | .015〜.45 | .0183333333〜.32 |

横向きの同じ入力に対する頭X出力を約1.286倍にし、口の未飽和域の傾きを約1.442倍へ上げます。口入力.10なら出力約.271、.20なら約.602、.32なら1です。笑顔や口形のマッピングを強める変更ではありません。

## 閉口境界を保つ

モデルは口開閉パラメータ.025以下で口内を隠します。上限.45だけを.32へ下げると、その表示開始はraw入力.025875から.022625へ早まり、閉じたつもりの小入力で口内が見えやすくなります。

そこで旧境界 `.015 + .025 × (.45 − .015) = .025875` を固定し、新しい入力下限を `(.025875 − .025 × .32) / .975 = .0183333333` にします。口を開いてからの反応を増やし、口内が隠れるraw入力域は保ちます。[部分マッピング例](../examples/nizima/FaceYawMouth.mapping.json)は既存プロファイルの対応2項目へ適用する値です。他の設定・クランプ等は保持します。

## 検証範囲

MOC・物理・8K画像は変更しません。頭X±27は既存Core検査の±30以内です。増えたXと他の最大入力を組み合わせた正負2ケースを、現行の髪物理・実PhysicsEngine60fpsで各481フレーム確認しました。髪7出力のclamp・非有限値0、最大absは後ろ髪約.658・前髪約.614で±1以内、停止後は最長約1.633秒で±.02へ収束しました。

最終プロファイルをVTSへ再ロードし、左右と口の境界・発話相当の短い合成入力を実OBS表示で確認しました。本人の実際の発話をラベル付けした認識精度試験とは区別し、カメラ映像は保存しません。直前のユーザー配置、ModelID、髪7風倍率、他のマッピングを保持します。

最終12ケースで、左右入力±15→頭X約±13.46、±30→約±26.96を確認しました。口入力0と新下限では出力ほぼ0、.023では約.01540、raw境界.025875では約.02496で口内非表示域に留まります。.10→約.27045、.20→約.60193、.32→約.99971で、OBSでも閉口と開口を確認しました。初期案の下限.015の試験は最終受入から除外しています。

合成入力を終了し、Camoの実15サンプルでは15/15で顔検出、範囲外yaw入力の出力は±27へ制限されました。本人の発話ラベルがないため会話時の認識精度とは扱いません。モデル本体・画像・髪物理・7風倍率・他のマッピングは保持し、変更は2項目の4数値だけです。
