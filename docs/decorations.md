# 花・蔓・金属装飾の切り抜き候補

原画のRGBから候補マスクを生成し、原画の色を保持した独立RGBAレイヤーへ抽出します。See-throughの学習カテゴリは変更していません。花・蔓の意味認識やSAM等の学習済み検出器ではなく、色による候補生成と手動マスクの補正機能です。

## 導入

`extras/ComfyUI-Revenant-Decorations` をComfyUI/custom_nodesへコピーし再起動。numpy/Pillow/torchのみを使います。ワークフローはPR #6の `ComfyUI-Revenant-Merge`（保存済みパーツ読込）と既存SeeThrough（PSD出力）も必要です。ローカルには両方配置済みです。

`workflows/seethrough-revenant-decorations.json` を開きます。

1. 01に原画、02に装飾除去済み下地を分割した `*_layers.json` を設定。JSONとPNGは同じフォルダに保持します。
2. 03は原画を下地PSDキャンバスに等比リサイズして中央配置します。自動位置合わせではなく、SeeThrough側の生成変形やクロップ差は解決しません。出力で位置を確認してください。
3. 04の赤い領域が候補。初期設定は青紫色（Pillow HSVの0〜255表現、H150〜205/S70以上/V50以上）。白い花芯、暗い輪郭などは自動候補から欠けるのでaddで含めます。服の裏地の青紫や髪の反射光を拾ったらexcludeで除外します。
4. 05で独立パーツ化。minimum_areaで小片除去、split_componentsで接続していない領域を分離。花と蔓が接続していれば一体のままです。意味的な1輪ごとの分割ではありません。
5. 06は装飾だけ、08は下地＋装飾の保存。Run後にDownload PSDを押します。Download Depth PSDは使用しません。

## マスク修正

03で配置後のキャンバスと同じ寸法の白黒PNGを用意し、Load Image (as Mask)のredチャンネルで読みます。白が対象、黒が対象外です。任意ノード11を必要数複製して04の端子へ接続します。

- region: 色候補を探す範囲。金属モードでは必須。
- add: 花芯や輪郭など不足部分を加える。region外にも追加可能。
- exclude: 裏地などを除く。最後に適用され、addより優先。

通常のLoadImageのMASK出力はアルファ反転です。白黒画像を通常のLoadImageのMASKへ無条件につながないでください。原画のsource_transparencyには通常のLoadImageのMASKを使用します。透過していない画像の場合、ComfyUIが64×64の空MASKを返すことがあり、本ノードは寸法不一致として停止します。その場合は原画と同寸法の黒マスクをsource_transparencyへ渡します。

金属はmode=silver_metalで低彩度高輝度の候補を作ります。銀髪・肌・服の反射と混同するため、対象領域regionを必ず用意してください。金属の暗い部分はaddで補います。金属を別パスで追加する場合prefixをmetalにします。重複名があれば停止します。

manual_onlyは色抽出を停止してaddマスクのみ使用。自動候補の精度が不十分な場合も手動マスクで抽出を完了できます。

## 合成の性質

抽出したRGBAはクロップPNGと座標で保持。元画像は書き換えません。中央配置時にリサイズした場合の色はリサイズ後の画素です。元レイヤーから装飾を消したり隠れた下地を補完したりはしません。下地に元の装飾が残っていれば二重になります。

Add Decoration Layersは最前面へ追加します。髪や腕の背後に回す蔓は別マスクで抽出し、PSD側で重なり順を調整します。XYは追加レイヤーにだけ適用。キャンバス不一致、重複名は停止します。既存レイヤーを変更しません。

## 検証

`python3 -m unittest discover -s tests -p test_decorations.py -v`

色候補、透過除外、追加除外マスク、金属領域必須、原画RGB保持、alpha二重乗算防止、接続領域分割、入力非破壊、座標、重複名・キャンバス検証、等比中央配置を確認。GUI実行・PSDダウンロード・最終切り抜き品質は未確認です。

## 補修済みマスクの再出力

`seethrough-revenant-decorations-repaired.json` は個別に補修したマスクを適用するワークフローです。マスク修復アルゴリズムを内蔵するものではありません。

- input/revenant_original.png: 元の装飾付き原画。
- input/revenant_decor_repaired_mask.png: 1448×1448の補修済み白黒マスク。
- output/revenant_body_repair_base_layers.json と参照PNG: 1448×1448へ拡大した下地。

これらの画像はGitへ含めていません。実行したユーザー環境には配置済みですが、他環境では個別に用意する必要があります。原画を等比中央配置したキャンバスとマスクの寸法・位置を一致させます。

原画の淡色・暗色も含めて選択し、3pxの閉処理、120画素以下の閉じた穴の補完、1pxの輪郭拡張を行ったマスクをローカルで作成しました。大きな蔓の輪は埋めない方針です。首元の衣装混入は手動範囲で除外しました。装飾は原画から抽出し、体の高精細化や隠れた部位の新規生成は行っていません。

出力は装飾のみ10レイヤー、下地込み32レイヤーの試作。PSDのヘッダー・レイヤー数・合成画像デコードを確認。輪郭の完全性、意味的な花1輪ごとの分割、Live2Dで動かした際の隠れた部分の充足を保証しません。

## 花芯・花弁を個別補修したレイヤーの再出力

`seethrough-revenant-flower-restored.json` は保存済みの修正RGBAを読み込み、位置と透過を保持してPSDへ保存します。服の混入を除く色選別で花芯・淡い花弁も欠けたため、ローカルで原画と比較し、花ごとに指定した領域内を原画の画素で復元しました。色判定を再実行すると補修が失われるため、この版は再抽出を通しません。

- 体込み: `output/revenant_with_decorations_flower_restored_layers.json` と参照PNG（32レイヤー）。
- 装飾のみ: `output/revenant_decorations_flower_restored_layers.json` と参照PNG（10レイヤー）。
- 初期値は体込み。装飾のみを再出力する場合は読込ノードのファイル名を変更します。
- PSD保存ノードは1個です。Run後にその `Download PSD` を使います。

画像・手動保護領域・補修マスクは個人素材のためGitへ含めません。このワークフローは補修済み素材を必要とし、別画像への自動補修やマスク修復処理を内蔵していません。細い蔓や葉の輪郭は別途調整余地があり、原画に隠れた花弁の新規生成も行っていません。

## GIMPで調整した装飾復元版

WindowsのGIMP 3.2.6で、作業中の文書を `revenant_before_gimp_adjustments.xcf` に退避し、コピー側を調整しました。花10層を再表示し、原画からチョーカー・ネックレス・リング・チェーン・タグ・耳飾りなど12層を復元して、体22層と合わせた44層にしています。白くなった衣装は保存済みの黒い衣装RGBAから読み直し、通常モードで合成しました。

ユーザー環境の `Desktop/model/SeeThrough-workflows` に `revenant_gimp_adjusted.xcf`、`revenant_gimp_adjusted.psd`、`revenant_gimp_adjusted-preview.png` を保存しています。編集元はXCFです。PSDもGIMPで再読込し、44層・黒い衣装・装飾の表示を確認しました。再読込の合成アルファ差は0ですが、RGBの合成結果には差があるため、PSDとXCFの画素完全一致は保証しません。

これらの個人画像と輪郭指定はGitに含めません。GIMPで非表示や順序変更を試した文書は原本として残し、調整版は別文書・別名で保存します。
